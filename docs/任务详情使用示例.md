# Tasks 详情使用示例

1. 启动 saddle，并在 Queue 的任务列表中选中要查看的任务。
2. 点击任务，或按 `Enter`，让 Tasks 区域切换到该任务的详情；也可以使用底部的 `Details`。
3. 在详情中查看任务的状态、耗时、正文、过程信息，以及 `Last check` 中记录的上次验收结果、时间和命令。
   `Last check` 只是之前保存的结果，详情页不会在本次打开时执行验收。
4. 页面打开后会立即查询详情；每次查询返回后约 5 秒再刷新一次。刷新期间可以继续查看和滚动内容。
5. 按 `Esc`，或点击 `Back`，返回任务列表；原来的任务选择和列表滚动位置会保留。
