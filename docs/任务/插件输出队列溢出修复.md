# 插件输出队列溢出修复

用户报告：Tasks 插件显示 fail；确认日志为 `output queue full`。

主控亲自修复，不委派，不操作真实任务或其他 agent。
Dispatch：`e37de990ef504bb89baa5e492b10d367`。

## 原因与改动

宿主每轮最多从输入队列转入 8 条消息，却只向插件管道发送 1 条。持续小批输入即使被公开有界队列正常接受、插件正常读取，也会在宿主内部积压到 64 条以上，被误当成协议错误并终止插件。

发送改为每轮最多 8 次非阻塞写入；内部队列满时暂停转入。暂不可写时保留消息与偏移，在下一轮继续。保留原消息/字节上限、顺序和关闭检查。无需更改 Drover 插件或任务数据格式。

- 修复后同一检查全部按顺序送达，没有丢失或重复。日志 `/tmp/saddle-output-queue-green.log`。
