- 严格分清：已记录的 doing/done/dropped；查询时重新计算的 Git 判据；上次验收缓存。历史不套当前判据；awaiting 的重算结果也不冒充完成时快照。done 不因今天重算失败而回退。
- 区间提交数不是任务独占提交数；main 顶端提交时间不是实际落地时间；end 是结账时 HEAD，不一定是当时 main。路由来自当前任务文件，需标明来源，不假装是历史不可变快照。
- 缓存状态建议 valid/stale/missing/invalid/unavailable；有效性按 task/main/command 匹配，不按年龄。即使 valid 也只是上次结果，未提交工作区变化不在现有校验键内。缺失记录不能声称从未验收过，历史不借用其他任务缓存。
