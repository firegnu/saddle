# 插件直接入口与覆盖界面实现

用户原话：“开始吧。”对应已交付的接入设计，先实现第一步 Counter 直接入口与工作区/居中覆盖界面；Attention 来源和 Drover 迁移另行进行。主控亲自实施，不委派，不改真实任务/服务。

工作分支 plugin-entry，worktree ../saddle-worktrees/plugin-entry。验收不扩写，以下记录工程设计与验证。

入口通过插件清单的 view/action/entry 声明，不按 Counter ID 特判。第一步一个视图 main、一个打开操作。侧栏直接显示已启用插件的入口，F6 从 Agents 进入入口键盘选择，↑↓选择、Enter 打开、Esc 返回；其他宿主保留键沿用。工作区/overlay 共用同一进程和画面通路，覆盖界面独立于持久化布局。尚在工作区显示的同一插件优先聚焦已有面板，避免出现第二个视图。

新能力 ui.entry.v1 / panel.overlay.v1 显式协商；旧清单没有入口仍兼容。initialize 告知 reserved_keys。当前 Counter 不消费业务上下文，不在本步实现 Attention 和任务目标。
