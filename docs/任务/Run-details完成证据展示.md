## 已核事实

- 旧 Run details 的 Completion checks 在 5fbe04f 接入显式任务流转时改为 Repository reference，并非本次项目接入界面移除了它。
- 当前详情显示 run、提交/验收/退回记录、Git 和旧检查记录，尚未汇总宿主遥测中的审查与收尾正文。
- 测试项目 saddle-e2e-20261002-113520 的 T1，本次 run 为 1818572ee4557cbcc65e05c023d35b63，trace 为 eb8eccba-0135-4750-a429-918d45a1c6c6。主控已报告审查、测试、本地合并和清理；遥测有 review.recorded 和 controller.note（closure）。公开 show 仍为 Running，Last check 为 unknown/no_record，Git HEAD/main 为 acf4379f9e1b240bfd6915fe4f9902c83ec23000。这不表示测试失败，也不表示用户已提交或验收。

## 建议的最小修复范围

- 在 Run details 增加只读的“主控审查/收尾报告”，展示已有记录的时间、声明的审查结果和正文，继续提供 Telemetry 跳转查看完整链路。
- Drover 通过宿主已有公开遥测接口取数据，精确关联项目、任务和当前 run；不直接打开 SQLite，不把其他任务或旧 run 的报告带入本次结果。
- 这是展示和只读数据接入，不修改任务状态机、队列、Submit/Accept/Return，也不执行检查或重发业务。
- closure 只是收尾记录，可能包含失败、阻塞或未完成事项；不能仅因记录存在就显示“运行成功”。passed 也须标明是对应审查记录声明的结果，不扩大为整个任务自动验收通过。
- 未记录、查询失败或没有报告时如实显示未知/无记录，不显示失败或成功，不要求为此开启遥测。旧 Run details 的仓库参考仍保留。
