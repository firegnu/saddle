### 取舍
- 入口放在 Agents 标题下单独一行，不与 Tasks 入口挤同一行；代价是列表少一行。无 workspace 的 `ui::draw` 也画 `Attention · 0`，两种绘制布局一致。
- N 等于清单行数，读取失败行也计入（让 0 只代表已知无事项）；加载中不猜数。
- 排序：等待 → 错误（均按名称）→ 各项目按登记顺序的待放行、失败（新的在前）→ 来源读取失败；New replies 按名称。
- 项目读取失败时该项目只显示失败行，不保留旧的待放行／失败条目，避免把旧快照当现状。
- 选中按条目身份保存；条目消失时退到原位置附近。鼠标点击行即打开（与设计一致），Mark seen 作用于键盘／滚轮选中的行。
- Tasks 有未完成的 Add／Edit／Delete／路径编辑，或写操作进行中且目标是别的项目时，不切换，提示先完成或取消，以免丢草稿。
- 跨项目周期取 5 × `refresh_ms`，不另加配置；每个项目仍是一次公开 `drover list --json`。
