# Drover 任务流转简化重构

## 授权与执行者

用户已授权开始实施，并明确：

> 整理的任务书不要盲目扩大范围。开始吧

> 另外让drover的主控自己做，不再委派agent去完成

由现有 `drover/main` 亲自实现、自测；不得启动或委派其他 agent（含实现、审查和内置子 agent）。`saddle/main` 负责接收交付、主控审查及后续 Saddle 接入协调。本文件不是新增队列项，不改变当前 T55/T57 状态。

## 用户要的结果与验收原话

> 各个task不能相互影响各自的任务扭转状态。而且我认为现在的很多问题都是类似调研之类的任务，不需要分支合并的。

> 保持简单可靠，没有必要套各种死板流程

> drover可以大动，而不是一直在缝缝补补。按照这个原则来

验收依据为以上用户原话；下面是已讨论确认的行为及实施边界，不另增产品需求。

## 已确认的行为

- 保留 Pending → Running → Awaiting release → Done。
- `done` 是明确提交验收：Running → Awaiting；不执行测试或以 Git、合并、收尾记号等检查控制转换。
- `go` 只接受 Awaiting 的交付：Awaiting → Done；不代替提交，不派发下一项。
- Running 和 Awaiting 均可退回 Pending，保留已有工作和此前交付记录；不操作分支、不自动重开。
- 停止 Loop 自动提交和自动派发。下一项必须明确派发；保留串行调度，不增加并发运行能力。
- Git、测试等仅为参考证据，失败、未知、陈旧不得伪装成通过；仓库参考信息不代表某个任务的归属或验收结论。
- 通知继续观察新进入 Awaiting 的任务，通知失败不改变任务状态；不扩展渠道、历史中心或补弹规则。
- worktree 的创建、开发、审查、合并、清理方式不变。开发交付仍需按任务要求审查验证，Drover 不再代替审查裁决质量。

## 本阶段实施范围：Drover

1. 围绕这些转换整理一个共享状态核心，CLI 和现有 curses 看板共用；只移动与任务流转直接相关的代码，不顺带实施其他重构任务。
2. 删除旧自动推进和统一 Git 门槛；退役相关 gate/hold/Loop 控制、Running 上 go 的连做逻辑、独立人工覆盖完成路径。旧配置和旧记录可读取，但不得重新启用旧行为。
3. 统一任务/运行身份、合法转换、目标过期和重复操作校验；状态写入失败不得报告成功。派发送达不确定性如实保留，不新增事务框架或自动重试系统。
4. 按已评估的新公开契约提供状态、操作目标和参考证据，统一成功/失败结果；可升级任务接口版本，不长期维护两套业务流程。
5. 保留原队列与事件中的历史事实，使用集中解码接入新核心；不凭空生成完成、验收或检查通过记录，不迁移真实数据。
6. 将通知观察与任务写操作分离，提供替代旧推进引擎的通知入口；本阶段只改代码及必要配置模板/操作文档，不操作真实服务。

`pause/resume` 沿用显式派发控制；退回不再额外隐式暂停项目，已有暂停状态保持。不为此增加新状态或新开关。

## 明确不做

- 不做分支归属、分支基线、任务类型系统、通用工作流框架、并发调度或自动交付识别。
- 不改 Corral 仓库及 `corral`、`corral-dispatch` 技能；若发现必需耦合，报告具体调用点，不擅自修改。
- 不在本阶段修改 Saddle 源码；交付准确的接口契约供后续接入，不扩展新页面。
- 不改真实任务/队列/配置，不替 T57 执行 done/go/人工完成，不删除或合并 T55/T38 分支，不补分支基线。
- 不安装、不重启、不停止真实服务或用户 agent，不更新真实命令入口；不单独发布新 Drover。
- 不翻修全部历史文档，不改变其他排队任务。

## 工作方式和验证

先读 Drover 的 AGENTS.md、当前交接和相关设计；使用独立分支/worktree，保留现有未提交工作。直接实现，不再委派。设计变更按该仓库约定记录，仅限本任务。实现提交留在任务分支，暂不合 main、不推送发布；完成后由主控审查，再与 Saddle 联调后统一切换。

行为改动遵守仓库的 RED → GREEN 要求，使用临时状态、合成仓库和假 Corral/通知器验证，命令在前台结束；不操作真实任务做测试。验证集中覆盖本任务行为，不另建大型测试框架：

- 各种交付均能明确提交，检查失败仍如实显示；A 遗留工作不挡 B。
- 提交、接受、两种退回及重开符合确认的转换；旧目标、重复请求及写入失败不误操作。
- 旧模式或残留标记不触发自动提交/派发；各入口一致。
- 合成旧 Running、Pending、Awaiting、人工完成和历史记录保留事实；通知去重且不推进任务。

运行适用的相关回归；报告执行与未执行的检查，不以探针替代产品测试或声称真实联调已通过。无关失败单列，不顺带修复。
