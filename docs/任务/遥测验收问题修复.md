## 实现

- Drover 详情工作线程经宿主公开 list/events/body 查询严格匹配项目、任务、run 的报告，固定事件上限分页。Run records 后展示报告身份、时间、声明的 verdict、正文和关联。无记录/读取失败明确显示未知；正文失败单独提示，Telemetry 完整链路入口保留。声明不等于用户验收，不以 closure 或 passed 自动推进任务。
- Submit/Accept/Return 的确认读取不增加报告查询。报告与既有任务详情一起接受项目/run/页面过期结果检查，切换不会把旧 run 报告带入新 run。
- 宿主通用 task.transition 允许零或一个 reason 正文；沿用现有内容寻址存储、校验及 Telemetry 正文查看器，不含 Drover 专用判断，不改 SQLite schema。
- Drover 退回业务成功落盘后，将同次原因原文交给 append；其他状态变更不带原因。旧事件不重写，旧版本无正文事件仍可读，遥测失败不重放或回滚业务。
- 不改 Corral、插件 SDK、项目规则或任何真实任务数据。
