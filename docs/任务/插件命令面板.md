# 插件命令面板

用户原话：“好的。开始实现吧”。对应已确认的轻量插件命令面板：搜索、名称、运行状态，Enter打开或切换，异常说明、禁用不可执行操作，管理作为次要入口，撤掉Counter常驻按钮。Saddle拥有外壳。主控亲自实现，不委派。

## 实施决定

固定宿主Plugins入口放在左侧Settings附近，所有插件共用；本轮不增加新快捷键。面板居中覆盖整个Saddle，约72列18行，小窗口裁剪适配。行点击仅选择，Enter或右侧动作执行；正常状态不占详细说明，异常展开原因。停用/失败项仍可搜索选择。

保留启用即启动、关闭视图保留进程的现有生命周期，不添加按需启动或后台服务。运行状态和已有视图由宿主计算，同一实例重复打开只复用。当前可执行操作仅打开/切换，不隐式启停。Settings等模态编辑不能被替换。面板内实时更新状态并保留稳定身份，执行时再次校验，失效点击取消。

设计决定不是扩写用户验收。

## 主控实现与审查

- 主控亲自实现，分支plugin-palette；没有委派、agent操作、真实队列/服务或上游仓库修改。
- 移除逐插件侧栏Bar及F6入口逻辑；固定Plugins按钮打开宿主Palette。Palette处理搜索/稳定选择/绘制/点击，Manager提供本实例状态与允许操作，App负责模态焦点与已有视图复用；不按Counter/Drover ID特判。
- 停用中立即禁止打开，不等工作线程更新。启动/停止/重启/故障/无响应/不可用均不可执行；后台和已有视图只Open/Switch。点击绑定所见Item（含进程PID），状态变化取消按压；Enter不能执行尚未重绘的状态。Manage定位所选插件；面板不是第二个生命周期管理器。
- 打开面板时底层输入和ctl布局写入被拦截，ctl inspect如实标记plugin_palette。面板可覆盖现有插件视图，取消恢复；切换只关闭旧显示，不重复进程或布局。清单、协议能力及SDK未改变，旧panel.v1插件继续可用。
- 搜索长度有界且达到上限仍可编辑删除；键盘/鼠标、1×1至常规窗口均有绘制检查。正常项不扩详情；故障说明与停用原因可见。不新增任意UI挂载点或快捷键配置。

## 交付边界

日常版更新后用户自行重启，已有插件登记保留。入口操作为点击左侧Plugins，输入搜索，Enter或行尾Open/Switch执行；管理入口为Manage plugins。本轮不迁移Drover、不实现Attention来源，也不把用户上轮看到Counter当成本轮面板已经目视验收。
