## 实施范围与顺序（一个分支完成）

1. 宿主存储/接口：库v2追加closed_at，reader兼容v1/v2且只读；writer事务迁移，按列名插入。trace close是不可逆控制操作，stored/duplicate幂等，总开关关闭也能结束；无库invalid且不初始化。结束事件复用recording.changed加closed:true，与置关闭/代数递增同事务，保留历史记录和内容。按定稿触发器保护，不提供降级迁移。
2. 读写边界：只读policy返回状态，不让show因closed失败；写入门按定稿优先级拒绝closed，已存在且closed优先于全局关闭，不改变未知ID和原有语法/关联校验位置。create同ID、dispatch、append、采集、set-recording重开均覆盖；set false/重复close幂等。合法旧context仍让业务执行一次并回执disabled；非法context仍按原规则拒绝。结束前已prepare的Capture不得补end，缺失仍未知，不设宽限。
3. 查询显示：list/show增加closed_at，已结束trace的recording_history/intervals按结束事件seq截止，无无限off尾段，未结束算法不变；保留原始events查询。Telemetry仅必要英文ended状态/事件文案，依据closed_at而非最后interval判断，无布局重做、无任务成功推断。
4. Drover：仅Accept/Return业务落盘、transition尝试后，使用已解析的同run trace调用宿主close（单独300ms预算）。结果增加telemetry.close并如实区分失败/未尝试；Submit不close、找不到trace不新建。退回原因仍先尝试写入，失败不能声称遥测完整，Drover原始原因保留；不重放业务、不影响任务状态成功。保留项目默认和派发本次覆盖，同run返工仍同trace，Return后新run按现有选择。
5. 分发技能：只改plugins/dispatch/resources/corral-dispatch的SKILL.md和遥测操作.md，以及revision2→3和指纹。落实一次口头授权只用于本任务、收尾调用close、下一任务不沿用ID、新要求新trace；同任务待决不提前close；Tasks绑定run由插件收尾。记录上下文可恢复、不按最新trace猜、不强制用户建立任务文件或删材料。项目AGENTS模板字节保持，安装资源不在本轮执行。

## 完成记录（2026-10-02，telemetry-task-boundary）

### 实际变更与取舍

- 宿主新增不可逆 `Store::close_trace` / `TraceCloseInput` / `telemetry trace close`。close 不要求总开关开启，无库 invalid 且不初始化；结束事件、暂停、代数递增和 closed_at 同事务，重复 close 幂等。v2 新库与 v1 写入迁移共用三个触发器定义，迁移失败回滚，按列名插入 trace；reader 兼容 v1/v2 不迁移。
- 只读 policy 返回状态；统一写入门对已存在的 ended trace 优先返回 disabled/trace_closed，保留未知 ID、语法与关联校验顺序。create/dispatch/append、prepare/begin/end 和重开均受此门约束；沿用现有 agent/plugin 入口，无须改 Corral 或业务执行回执。合法旧 context 业务仍执行一次，无效关联仍拒绝；在途 end 不设宽限。
- list/show 增加 closed_at；区间/控制历史按结束事件 seq 截止、保留时间原值，无无限 off 尾段，原始 events 可查。Telemetry 只增加英文 ended 状态和 Trace ended 事件名，无布局或任务成功推断。
- Drover 仅在 Accept/Return 业务保存、transition 尝试之后，以本次解析出的同 run trace 调用 close，独立300 ms预算；流转结果 `telemetry.close:{status}` 与原 transition status 分开，Submit/无可用trace为 not_attempted。transition 失败仍尝试 close，原因缺于遥测的风险如实保留，Drover 原始退回原因不变；无重放/回滚业务。
- dispatch 仅改资源 SKILL.md、遥测操作.md 及 lib.rs revision/指纹：一次口头授权只用于本任务，任务真正完成且无待决时结束，Tasks run 由插件结束，后续独立任务不继承 ID；上下文可恢复，不要求新建任务文件或删除材料。revision=3，资源指纹 `sha256:efb2ff8bef91ef8d52772c267ace1ee65b05b8f70e9098c78931b9e2219e5407`。项目模板与基线逐字节一致（SHA256 `22339f4674469d1b8a5041086f4aa3e5a4b5e9d53f356f946dd1a06cc2f73384`），资源 README 未改。
