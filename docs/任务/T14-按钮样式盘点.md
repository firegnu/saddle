## 样式建议

- 普通内部按钮：细圆角框，白色稍偏灰，无单独填充色，沿用所在面板底色；左右各少量留白，宽度随文字，不拉成长块。
- 悬停/键盘焦点：边框适度提亮；必要焦点标识沿用现有规则。禁用仍要弱化，危险操作保留危险色。
- 底部操作栏：保留单行 ‹…›，包括 Create/Save/Apply 等提交动作，避免同一底栏混用两种高度。
- 候选列表仍是列表；输入框仍通过字段标签、编辑内容与光标识别，不混为普通按钮。

内部按钮示意：

```text
╭─────────╮  ╭──────────╮
│ ● Codex │  │ ○ Claude │
╰─────────╯  ╰──────────╯
                         ‹Cancel Esc›
```

### 右侧 Tab：更轻的同系列按钮

```text
╭───────────╮ ╭───────────╮ ╭───╮
│ Tab 1   × │ │ Tab 2   × │ │ + │  ‹ ›
╰───────────╯ ╰───────────╯ ╰───╯
```

- 非当前 tab：低对比灰色细框、普通文字、无底色；当前 tab 只提亮到灰白并适度加粗名称，不常驻大块黄色/亮色，也不用粗边框。
- × 放在对应 tab 的轮廓内，仍是独立关闭命中区；点击 tab 主体切换、点击 × 关闭，交互不改。加号用同系列小按钮；左右翻页保留低调箭头，不再各加一大块框。
- 保留 Tab N 命名，不把本轮扩展为自动命名、重排或拖拽。显示焦点和当前选中的区别沿用现有终端边框/状态栏。
- 真实终端完整描边最小占三行，比现在单行 tab 条多两行，终端内容高度相应减少。这是建议方案的明确成本，尚未实施；不同时增加额外外框或上下留白。

## 实施时需注意的局部工作

源码已有三行无填充圆角按钮绘制，不需要另搭控件框架；但不能把所有 draw_compact 全局替换。当前 New 按一行按钮安排字段高度、Split 面板固定六行、tab 条固定一行，必须随描边高度同步改布局和命中范围，避免挤掉输入/取消、遮挡内容或坐标错位。现有选择/取消/移动身份保护保持。
