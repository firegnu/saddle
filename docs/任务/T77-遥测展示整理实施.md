## 完成记录（实施，2026-10-04，saddle/dev-t77-design）

- **设计一致点**：认同主控复核的四项细化，已写入方案“一致结论”（62560ac），无实质分歧。四项是：`Look further` 放在状态/更新提示之后、Key events 之前，完整链路链接放第一行，run/trace 不重复；报告数按读取状态表述，unknown 不写 0，正文读不出的单独计数；退回条数只标本轮；正文链接的点击区随实际折行和滚动，只覆盖链接文字。
- **改动**：
  - `detail.rs`：新增 `look_further`。Key events 改为先 Next step，再审查/收尾、提交/验收，最后四类投递节点，并去掉重复的去向说明。报告标题带份数；Event/Dispatch 合成一行，和 Trace 一起改 muted。`push` 记录链接每段折行后的行、列和宽度，由 `lines_and_links` 返回；原 `lines` 只在单元测试中使用。
  - `queue.rs`：页签行链接改为 `Open in Telemetry ↗`（放不下时 `Telemetry ↗`），强调色加粗、无下划线，和页签同排时前面有细分隔线。正文链接只给可见的片段登记 `Hit`，key 与页签行相同（`telemetry_click()`，打开全部轮次），处理函数未改。Help 行同步更新。
  - 文档：README、DESIGN.md 新增 T77 一节。
  - 测试：新增 `ui.rs` `run_details_point_further_first_and_the_body_link_opens_every_run` 和 `detail.rs` `look_further_counts_reports_by_read_state_and_tracks_the_wrapped_link`。另调整两处既有断言，没有放宽：`Look further` 里的 `Run records` 标签会先于同名节标题被找到，所以节标题样式检查与先后顺序检查都改为定位节标题行本身；`returned_pending_run_details_show_the_saved_history` 的画面从 150×48 加高到 150×60，因为首屏多了 `Look further`，退回历史被挤到原高度以下，断言内容不变。
- **验证**：
  - RED：新 ui 测试在实现前失败，原因是缺少 `Look further` 内容。新单元测试依赖新接口，没有单独跑出 RED。
  - GREEN：`cargo test -p saddle-drover-plugin --lib --test ui --test ui_drover_polish` 结果为 8、24、3 项全部通过；`cargo clippy -p saddle-drover-plugin --all-targets -D warnings` 通过；`cargo fmt --check` 和 `git diff --check` 通过。
  - 画面：用临时合成样例看过 140×40 和 80×24 两种尺寸，样例已删除。
  - 未运行：process 测试（协议和进程接口未变；它按子串 `Telemetry ↗` 查找，新文字仍然包含）、全仓测试与 Clippy，留给主控阶段集成。
- **剩余限制**：两处链接只能鼠标点击，沿用现状，没有新增键位；没有实际终端里的观感确认。
