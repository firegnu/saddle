## 要做的
- 只改 saddle，保存并恢复 tab、分屏方向与比例，以及窗格对应的 agent。
- 布局变化时自动保存，正常关闭 saddle 时再保存一次。
- agent 退出后，保留窗格及原名称、目录；用户先关掉全部 agent 再退出 saddle，第二天仍能恢复工作位置和提示信息。
- 启动时自动恢复上次布局。仍在运行的原 agent 通过现有 corral 公开接口重新接入；已退出的显示占位，并提供“创建新 agent”和“选择已有 agent”入口。
- 默认不自动启动已退出的 agent，不承诺恢复已结束的对话。

## 文件位置与失败行为
- 默认 `~/.local/state/saddle/layout.json`；设置了绝对路径的 `XDG_STATE_HOME` 时使用 `$XDG_STATE_HOME/saddle/layout.json`。不放入项目仓库或现有 config.toml。
- 首次启动、文件不存在：正常打开默认布局。
- 保存目录不存在：第一次保存时自动创建。
- 文件损坏或版本不支持：提示无法恢复，使用默认布局，保留原文件避免覆盖。
- 没有写入权限：提示保存失败，当前 saddle 仍可正常使用。

## 已确认的占位操作
- 普通终端恢复占位，由用户手动打开新的终端，沿用原启动目录，不重放执行过的命令。
- 已退出 agent 的“创建新 agent”预填原名称和目录，模型与命令使用当前默认值，用户确认后创建。
