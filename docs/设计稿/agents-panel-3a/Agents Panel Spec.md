# Agents 侧栏 · 实现规格

视觉参考：`agents-panel-3a.png`（设计稿 3a 截图）。本文件是实现依据，二者冲突时以本文件为准。

## 0. 待确认的假设（实现前请核对）
- `C<n>(<upstream>)` 中 `n` = 本地落后上游的提交数。
- `ATT <n>` = 当前连接到该会话的客户端数；`⦿` = **本客户端**正连着该会话。
- 若含义不同，只需改第 4 节中对应字段的渲染，其余规则不变。

## 1. 整体结构
```
┌ Agents · <总数> ─────────── Tasks · Running Tab ┐   ← 头部，下方 1 条分隔线
│ <group>/ ──────────────────────────────── (<n>) │   ← 分组标题
│ ┃ <agent 条目>                                   │
│ ┃ <agent 条目>                                   │
│                                                  │   ← 分组间空 1 行
│ ...                                              │
│ [Attached]  n New  s Sort  x Stop                │   ← 底栏，上方 1 条分隔线，贴底
└──────────────────────────────────────────────────┘
```
- 面板左右内边距各 1 列。
- 头部：`Agents · N` 粗体左对齐；右侧 `Tasks ·`（暗色）+ `Running Tab`（蓝色）。
- 分组标题：`name/`（橄榄色粗体）+ `─` 填满剩余宽度（极暗色）+ `(n)`（暗色）右对齐。取代原树形 `└─` 连线。
- 底栏：按键字母用橄榄色粗体，标签正常色；`x Stop` 整组红色；`[Attached]` 暗色（激活时改为正常色）。

## 2. Agent 条目
左侧 1 列竖线 gutter（每条独立一段，连续排列）+ 1 列内边距。行定义（`I` = 2 列缩进）：

| 行 | 内容 | 显示条件 |
|---|---|---|
| R1 | `状态点` `名称` … `agent` `状态` `时间` | 总是 |
| R2 | I `标题` | 展开 且 标题 ≠ 分组名 |
| R3 | I `DOING/ASK/ERR` `内容` `· 时长` | 展开 且 有活动 |
| R4 | I `⎇ 分支` `↓n 上游` … `+a -d ?u` | 展开 |
| R4b | I … `+a -d ?u`（右对齐） | 展开 且 diff 放不进 R4 |
| R5 | I `路径` | 展开 |
| R6 | I `hash · ATT n · VIA via` | 展开 |

条目之间不留空行；选中条目整条加底色。

### R1 固定列（50 列面板）
| 列 | 宽 | 说明 |
|---|---|---|
| 状态点 | 1 | 见第 3 节 |
| 名称 | 弹性 | 粗体；超出用 `…` 截断；**不再**另起一行显示全名 |
| agent | 8 | `✳ claude`（橙）/ `>_ codex`（青），粗体 |
| 状态 | 9 | `idle` / `⣾ working` 等，粗体 |
| 时间 | 5 | 右对齐；attached 时为 `⦿ 11s` |
列间距 1。各列跨条目、跨分组对齐。

## 3. 状态
| 状态 | 点 | 点/状态色 | 附加 |
|---|---|---|---|
| waiting | `?` | 黄 | R3 显示 `ASK <待确认内容>`（黄） |
| error | `!` | 红 | R3 显示 `ERR <错误摘要>`（红） |
| working | `◐◓◑◒` 循环 | 蓝 | 状态前加 braille `⣾⣽⣻⢿⡿⣟⣯⣷` 循环（紫）；时间列蓝色；R3 `DOING <tool>`（蓝） |
| idle | `○` | 绿 | — |
| exited | `✕` | 极暗 | 名称与时间变暗 |

- 动画：braille 每 120ms 一帧，圆点每 360ms 一帧。
- **组内排序**：waiting → error → working → idle → exited；同状态保持原顺序（或按 `s Sort` 当前规则）。

## 4. 字段渲染规则
- **标题（R2）**：原样显示（含前缀图标如 `✳`、`⠪`）；等于分组名（去掉 `/`）时隐藏整行。
- **分支（R4）**：`⎇ <branch>`；若 branch == 名称，只显示 `⎇`（不重复名称）。
- **上游（R4）**：`C<n>(<up>)` → `↓<n> <up>`。`n=0` 时 `↓0` 极暗；`n>0` 时 `↓n` 黄色。上游名暗色。
- **diff（R4 右侧）**：`+a`（绿）`-d`（红）`?u`（暗），间隔 1 列，右对齐。
  - 放置判定：`len(R4 左侧) + 1 + len(diff) ≤ 可用宽度` 则同行，否则整组移到 R4b 右对齐。**禁止在 diff 内部折行。**
  - 可用宽度 = 面板列数 − 6（左右内边距 2 + gutter/内边距 2 + 缩进 2）。50 列时为 44。
  - 长度按终端显示宽度计算（宽字符算 2）。
- **路径（R5）**：若末段 == 分组名，只显示父目录（`…/personal_projs/`）；否则完整显示。超宽时**从左侧**截断，保留末段。
- **R6**：`hash`、`VIA via` 极暗；`ATT n` 在 `n>0` 时绿色，否则极暗。
- **活动（R3）**：`<LABEL> <内容>` 用状态色，`· <时长>` 暗色；超宽右侧 `…` 截断。

## 5. 选中与 attached
- 选中（光标）：该条 gutter 变为 2 列宽度不变的橄榄色竖线 + 整条底色 `#2b2621`。未选中 gutter 为极暗色竖线。
- attached（`⦿`）与选中相互独立，可以在不同条目上。

## 6. 折叠模式
- 开启时：未选中条目只显示 R1（上下 2px 内边距），选中条目完整展开。
- 默认：agent 总数 > 5 时开启，≤ 5 时关闭；可用快捷键切换（建议 `z`，并在底栏显示）。

## 7. 窄宽降级
按顺序应用，直到放得下：
1. 面板 < 50 列：agent 列缩为图标 `✳` / `>_`（宽 2）。
2. 名称截断（`…`）。
3. 时间、状态列始终保留。
其余行按第 4 节各自的截断规则处理。

## 9. 验收
- 50 列下，示例数据（corral / drover / saddle×2）无任何折行。
- 注入 `+12847 -3291 ?128`，diff 整组移到下一行右对齐。
- 切换选中到 `saddle/main`，只有该条高亮，同组另一条不受影响。
- 42 列下，agent 列显示为图标，各列仍对齐。
- 5 种状态的点、颜色、排序符合第 3 节。
