# Diff

Saddle 的只读实时 Git diff 插件。打开即按文件连续展示当前 worktree 的全部未提交改动，包括未忽略的未跟踪文件；无需选中文件。独立进程，使用现有 Rust SDK，不依赖 Drover。

## 安装

构建一次：

```sh
CARGO_TARGET_DIR="$HOME/Developer/personal_projs/saddle-worktrees/.target" ./plugins/diff/package.sh
```

在 Saddle 的 Settings → Plugins → Add local 填入 `plugins/diff/dist/diff-plugin` 的**绝对路径**，读取清单、添加并启用。从主界面 Plugins 选 Diff 即可，不需要重启 Saddle。

默认居中；也能从标签条 `+ → Plugin…` 或 `Split → 方向 → Plugin…` 打开。同一插件视图移动到新位置，保持状态，不创建第二个进程。目录来自打开它的 agent/终端；切换到另一个 agent 后重新从 Plugins 打开，会跟随新的来源目录。切换焦点本身不会自动切换正在阅读的仓库。

## 阅读

- `1` 全部：HEAD → 工作区，包括未跟踪文件。
- `2` 未暂存：index → 工作区，包括未跟踪文件。
- `3` 已暂存：HEAD → index，不包括未跟踪文件。
- `↑↓` / `j k` / 滚轮：滚动；`PgUp/PgDn`：翻页；`Home/End`：首尾。
- `←→` / `h l`：横向滚动；`[` / `]`：前后文件；`n/p`：前后差异块。
- `f`：显示/隐藏文件定位列表；点击列表只跳转，不过滤内容。
- `v`：自动/单列/左右对照；空间不足时左右对照退回单列。
- `r`：立即重新检查；`Esc` 关闭视图，`Ctrl-]` 返回宿主焦点。

一次扫描结束后约 750ms 再检查，串行执行；大型仓库的实际更新会更慢。数据未变不重建画面，数据变化尽量保留文件及行内容位置。插件失焦仍更新，可放在 agent 旁边观看。关闭视图取消检查；隐藏到其他 tab 仍保持打开，会继续检查。重开时检查最新内容。读取失败明确显示错误，并将保留的内容标为过期。

## 文件与边界

Git 负责基线、重命名、模式及属性；similar 标出行内改动，syntect 提供常见语言语法色（差异块边界重新初始化语法状态）。普通文本、新增、删除、重命名、权限变化和符号链接可读；二进制和 `-diff` 属性文件显示摘要，未知扩展按普通文本显示。未解决冲突给出明确提示，不当作普通双边 diff。子模块显示 gitlink 提交变化，不递归读取内部未提交内容。

仅预览 UTF-8 文本；不支持的编码明确提示。单文件/旧版本 512 KiB、单行 16 KiB、总预览约 4 MiB、单文件 5000 行、总 20000 行有界；超出时仍列出文件并标明限制。文件列表本身有 4 MiB 输出上限，超过则明确报错。所有预算用于避免巨型文件拖住界面，不表示 Git 数据被截断或修改。

不执行 external diff、textconv、clean/smudge/process filters、fsmonitor，不自动获取缺失对象，不写 Git index。需要外部过滤器的仓库会明确失败；不偷偷运行过滤器或把失败显示成没有改动。每个 Git 命令最多 5 秒，并响应关闭/切换取消。

没有暂存、丢弃、提交、文件编辑动作，也不会启动 agent、推进任务或发通知。
